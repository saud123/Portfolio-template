PROJECT 01

Full-Stack AI Dental Clinic & Voice Receptionist

Book me a cleaning Tue 10:30 confirmed ✓
FastAPINext.js Gemini 2.0 FlashPostgreSQLpgvector

Problem — Clinics lose hours to phone scheduling, and generic chatbots can't touch patient records safely.

Built — A FastAPI backend wiring Gemini 2.0 Flash for multi-turn clinical reasoning with custom tools (book / cancel / reschedule) over secure REST endpoints. A multilingual voice pipeline (FFmpeg STT → Gemini → ElevenLabs / gTTS) and a RAG memory system on pgvector retrieve history and summarise closed sessions.

Safety — A two-layer guardrail (classifier + prompt rules) blocks non-clinical queries and prevents unauthorized diagnosis.

Learning → Guardrails are a product feature, not a patch. Edge-case evaluation mattered more than the happy path.
PROJECT 02

Multi-Agent Financial Intelligence — PSX

PythonFastAPI PostgreSQLPineconeGemini

Problem — Retail investors get scattered data and confident-sounding noise instead of grounded analysis.

Built — A supervisor agent routing to five specialists (market data, sentiment, risk, macro, RAG) in parallel. A document pipeline (Playwright → PyMuPDF OCR → Sentence-Transformers → Pinecone) indexes quarterly reports for retrieval.

Reliability — Three-provider fallback (Gemini → Groq → OpenRouter) with retries and rate limiting, served over FastAPI with SSE streaming to a vanilla JS frontend.

Learning → A lookahead-safe backtest proved deterministic math — not LLM confidence — should drive the decision.
PROJECT 03

Explainable Loan Default Prediction & Risk Dashboard

PythonScikit-Learn SHAPStreamlit

Problem — A black-box default model is useless to a risk team that must justify every rejection.

Built — An end-to-end pipeline over 32K+ loan records — cleaning, imputation, feature engineering — landing on a Gradient Boosting model at 93.4% accuracy and 0.946 AUC-ROC.

Explainability — SHAP values surfaced the top drivers (loan-to-income ratio, prior defaults) inside a Streamlit dashboard for real-time scoring and risk-based pricing.

Learning → Accuracy sells the model; interpretability gets it deployed.
